## Featured Work

### [RISC-V Edge AI Cat/Dog Classifier](https://github.com/Meshal-ali-alanazi/catdog-riscv-edge-ai)

Tiny CNN cat/dog classifier for a RISC-V edge-AI workflow, combining PyTorch
training, quantized firmware export, and Renode simulation benchmarks.

Key points:

- Trains a compact computer vision model in PyTorch
- Exports quantized firmware headers for embedded inference
- Uses Renode-modeled benchmark results to compare execution paths
- Documents simulation scope, limitations, and reproducibility steps

### [RISC-V Single-Cycle CPU](https://github.com/Meshal-ali-alanazi/riscv-single-cycle-cpu)

Custom educational RV32I single-cycle CPU in Verilog with a self-checking
SystemVerilog testbench.

Key points:

- Covers ALU, branch, jump, load, and store instruction groups
- Uses a modular RTL structure for fetch, decode, register file, control, and
  execute/memory stages
- Includes simulation scripts for CPU regression checks
- Connects with the RISC-V edge-AI work as the CPU-side hardware project

### [enterprise Network Design](https://github.com/Meshal-ali-alanazi/Enterprise-network-design)

Cisco Packet Tracer enterprise network project with a LaTeX report, topology
diagram, and configuration deliverables.

Key points:

- Documents an enterprise-style network topology
- Includes Packet Tracer project files and report assets
- Shows network planning, routing/switching concepts, and technical reporting
