## Featured Projects

### RISC-V Edge AI Cat/Dog Classifier

Tiny CNN cat/dog classifier with PyTorch training, quantized firmware export,
and Renode simulation benchmarks for a RISC-V edge-AI workflow.

Repository: [catdog-riscv-edge-ai](https://github.com/Meshal-ali-alanazi/catdog-riscv-edge-ai)

Highlights:

- PyTorch training flow for a compact image classifier
- Quantized firmware headers for embedded inference
- Renode-modeled accelerator benchmark results
- Documented simulation scope and known limitations

### RISC-V Single-Cycle CPU

Custom educational RV32I single-cycle CPU in Verilog with a self-checking
SystemVerilog testbench.

Repository: [riscv-single-cycle-cpu](https://github.com/Meshal-ali-alanazi/riscv-single-cycle-cpu)

Highlights:

- RV32I instruction support for ALU, branch, jump, load, and store groups
- Modular Verilog RTL structure
- Self-checking simulation testbench
- CPU-side companion project for the RISC-V edge-AI work

### AI Classification

Python-based image classification project exploring model training and
evaluation for small computer vision workloads.

Repository: [AI-classification](https://github.com/Meshal-ali-alanazi/AI-classification)
